# Message composer

Messages can contain up to 120,000 characters. If a draft is longer, T3 Code keeps it in the
composer and shows how many characters need to be removed. Shorten the draft or split it into
multiple messages, then send again in the same thread.

While Codex is working, the send button remains available beside Stop. Sending another message
steers the active turn, so Codex can use the new direction without waiting for the current turn to
finish. The draft stays in the composer if Codex rejects the message.
